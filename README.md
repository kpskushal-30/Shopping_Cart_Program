# Shopping_Cart_Program
A CLI-based shopping cart application built in Python that allows users to add products, remove items, and generate a total bill.

A simple command-line shopping cart application built using Python.

## Features
- Add products and their prices
- Remove items from the cart
- Display all items in the cart
- Calculate total bill

## Concepts Used
- Python lists and tuples
- Loops
- User input handling
- Basic data structures

## How to Run

Python---> Shopping Cart.py
